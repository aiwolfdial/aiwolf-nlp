大会の情報はすべて**大会定義シート**に書きます。

👉 [大会定義シートを開く](https://docs.google.com/spreadsheets/d/1NzFe2zl2lPqE9MQSbj_PVA4LMDwuje9Uez7GmGDdORg/edit)

閲覧は誰でもできます。編集するには管理者に権限をもらってください。

## タブの構成

| タブ | 中身 |
| --- | --- |
| 大会 | **行が項目、列が大会**。大会ごとの値を書く主なタブ |
| 大会_en | 英語ページで使う値。列は「大会」タブと連動している |
| トラック / トラック_en | 大会横断のトラック一覧（ターン式 5人村など）と、チーム当たり試合数の既定値 |
| ルール | 大会横断のルールセット（1 発話の文字数、制限時間など）。列が国際・国内などのセット |

トラックとルールは大会をまたいで共通です。大会の列では「どのトラックを開催するか」「どのルールセットを使うか」を選ぶだけです。

## 新しい大会を始める

1. 「大会」タブで、空いている列の **1 行目に大会 id** を書きます（例: `inlg_2027`、`aiwolfdial2027_springjp`）。
   id は半角の英小文字・数字・`_` だけで、サイトのページ名やフォームにも使われます。
1. その列の値を埋めます。ドロップダウンやチェックボックスは最初から付いています。
1. 英語のページも作る大会は「サイトの言語」を「両方」にし、「大会_en」タブの同じ列を埋めます（id は自動で出ています）。
1. メニュー「**大会データ → 大会データを更新**」を押します。

前回大会の値をコピーする必要はありません。隣の列の過去の大会を見ながら書けます。

## 色の意味

- **赤**: 必須なのに空のセル。項目名の頭に「＊」がある行が必須です。会期が終わった大会の列は赤くなりません。
- **D1 の用途の切り替え**: D1 のドロップダウンで「フォーム」「サイト」などを選ぶと、その用途で**必須の行が濃い黄色**、使うだけの行が薄い黄色になり、関係ない行は薄い字になります。赤もその用途で必須の行だけに絞られます。「全部」で元に戻ります。
- 会期が終わった大会の列は、編集しようとすると警告が出ます。直す必要があるときだけ編集してください。

## 書き方の決まり

| 項目 | 書き方 |
| --- | --- |
| 日付 | `2026/07/04` |
| 期間 | `2026/10/17〜10/21`（年をまたぐときは `2026/12/28〜2027/01/05`） |
| 「〜」付きの日程（本戦開始など） | `2026/07/06〜` |
| 担当者などの一覧 | カンマかスペースで区切る（`suzuki, tanaka`） |
| 日程 | 使う種類（登録締切、本戦開始、結果返却など）の行だけ埋める。表示文が空なら種類の名前（「結果返却」など）が出る |
| 回 | 回が 1 つの大会は「回 1」だけ埋める。2 回ある大会は「回 2」も埋める |

未定の値は空のままで構いません。ページには「決定次第掲載します」と出ます。

## 大会データを更新する

メニュー「大会データ → 大会データを更新」を押すと、GitHub の aiwolf-nlp-contest-data が自動で更新されます（30 秒〜1 分）。
終わるとダイアログに結果が出ます。

- **更新しました**: 変わった大会が書かれます。続けて[サイトの更新](./edit_website.md)を行います。
- **変更はありませんでした**: シートと大会データが同じです。
- **注意**: 未記入の必須項目、読めない日付、登録締切が本戦より後、学会期間が本戦より前、などが出ます。シートを直してもう一度押してください。

大会データが更新されても、**公開サイトはまだ変わりません**。サイトに反映するのは、サイト側で取り込んで確認したときです。

### 更新ボタンの準備（初回だけ）

ボタンは押す人の GitHub トークンで動きます。

1. GitHub の Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token を開きます。
1. Resource owner を `aiwolfdial`、Repository access を「Only select repositories」で `aiwolf-nlp-contest-data` だけにします。
1. Permissions の Repository permissions で **Actions を Read and write** にします（ほかは触らない）。
1. 作ったトークン（`github_pat_...`）をコピーし、シートのメニュー「大会データ → GitHub のトークンを設定」に貼ります。

初回は Google の承認画面が出ます。「このアプリは Google で確認されていません」と出たら「詳細」→「移動」→「許可」で進めてください。
トークンは本人専用の領域に保存され、ほかの人には見えません。期限が切れたら同じ手順で貼り直します。

## よくある間違い

- **年の書き間違い**: 3 月の学会を前の年で書くなど。更新の結果に「学会期間が本戦より前」と出ます。
- **前の大会の値が残る**: 企画セッション名など、たまにしか変えない項目に注意してください。
- **半角の引用符**: 英語の文で `"…"` と書くとそのまま出ます。元の表記に合わせて `“…”` を使ってください。
