大会の結果とは別に、運営が同じ条件で回している 2 つのベンチマークをまとめています。

- **エージェント**: 公式サンプルエージェントに公開 LLM を載せ替え、大会と同じルールで総当たりに近い対戦を行い、LLM-as-a-Judge の相対評価で順位付けしたものです。大会に出るエージェントの土台になる LLM の比較に使えます。
- **相対ジャッジ**: 大会で使っている順位付けの LLM ジャッジについて、過去大会の人手評価（評価者ごとの順位）とどれだけ一致するかを公開 LLM ごとに測ったものです。大会のジャッジに使うモデルを選ぶ根拠にしています。
- **カウントジャッジ**: 発話ごとに減点・加点の事象を数える別方式の LLM ジャッジです。同じ人手評価との一致度と、エージェントのベンチマークに適用した結果を載せています。
- **ゲームスコア**: 対戦記録だけから計算した、ジャッジに依らないスコアです。
- **レビュー**: 相対評価とゲームスコアを突き合わせた分析です。
